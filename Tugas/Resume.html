Hari ini belajar mengenai struktur konten dan semantik dokumen HTML.

1. Pengenalan HTML dan Anatomi Dokumen

HTML (HyperText Markup Language) adalah bahasa markah standar untuk menyusun struktur dokumen web. Dokumen HTML diawali dengan deklarasi <!DOCTYPE html> yang memberi tahu browser bahwa dokumen menggunakan standar HTML.

Anatomi dasar dokumen HTML terdiri dari dua bagian utama:

  1. Head: Berisi informasi metadata tentang dokumen, seperti character set, judul halaman, dan tautan CSS. Informasi ini tidak ditampilkan langsung sebagai konten utama halaman.
  2. Body: Berisi seluruh konten yang ditampilkan kepada pengguna, seperti teks, gambar, tabel, formulir, dan tombol.

2. Tag Semantik HTML vs. Non-Semantik

Tag Non-Semantik

Tag non-semantik, seperti <div> dan <span>, tidak menjelaskan makna khusus dari konten yang berada di dalamnya.

Tag Semantik HTML

Tag semantik menjelaskan peran dan struktur konten sehingga lebih mudah dipahami oleh pengembang, browser, screen reader, dan mesin pencari.

Beberapa tag semantik utama HTML antara lain:

  • <header> — Bagian kepala halaman atau artikel.
  • <nav> — Area tautan navigasi.
  • <main> — Bagian konten utama.
  • <section> — Kelompok konten yang berhubungan secara tematik.
  • <article> — Konten mandiri, seperti berita atau postingan blog.
  • <aside> — Konten sampingan atau pelengkap.
  • <footer> — Bagian bawah halaman yang berisi informasi tambahan.
